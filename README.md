# 筋トレ記録

ワークアウトを記録する単一 HTML のウェブアプリ。ビルド不要・依存ライブラリなし。

- **記録** — 日付ごとに種目・重量・回数・セットを記録。前回の値がプレースホルダに出るので、そのままチェックすれば引き継げる
- **分析** — 週別の総ボリューム、種目別の推定1RM / 最大重量 / ボリュームの推移（Epley 式）
- **種目・ルーティン** — 日本語の主要種目をプリセット。よく使う構成をルーティンとして保存し一括読込
- **同期** — 非公開 Gist にデータを保存し、スマホと PC で同じ記録を共有
- **オフライン対応** — PWA なので圏外でも起動できる（ホーム画面に追加して利用）
- **記録形式** — 種目ごとに 重量x回数 / 回数のみ（自重）/ 時間・距離（有酸素）を選べる
- **自己ベスト** — 更新した種目に PR バッジ、前回との差も表示
- **からだ** — 身長と体重を記録し、BMI と推移を表示
- **配色** — 設定からアクセント6種 x 背景3種を切り替え

## 使い方

`index.html` をブラウザで開くだけ。データは端末の `localStorage` に保存されます。

## GitHub Pages で公開する

```sh
git remote add origin https://github.com/<ユーザー名>/kintore.git
git push -u origin main
```

その後リポジトリの **Settings → Pages** で Source を `Deploy from a branch` / `main` / `/ (root)` に設定すると
`https://<ユーザー名>.github.io/kintore/` で開けます。スマホの Safari / Chrome で開き、
「ホーム画面に追加」するとアプリのように使えます。

## Gist 同期の設定

1. GitHub の **Settings → Developer settings → Personal access tokens (classic)** で
   **`gist` スコープだけ**を付けたトークンを作成
2. アプリ右上の「バックアップ」→ トークンを貼って「今すぐ同期」
3. 初回に非公開 Gist が自動作成され、Gist ID が入力欄に入る
4. 2 台目では同じトークンと **同じ Gist ID** を入力して同期

### 同期の仕様

競合は「最終更新が新しい方を採用」で解決します。

- 種目・ルーティンは名前をキーに突き合わせ
- セッションは**日付単位でまるごと**新しい方を採用
- 削除は墓標（tombstone）を記録するため、同期で復活しません

同じ日を 2 台で同時に編集すると、後から保存した側だけが残ります。

### セキュリティ上の注意

アクセストークンはブラウザの `localStorage` に**平文で**保存されます。

- 共用端末では使わないでください
- 必ず `gist` スコープのみのトークンを使ってください（リポジトリへの書き込み権限は不要）
- 不要になったらアプリの「接続を解除」と、GitHub 側でのトークン失効を行ってください

## バックアップ

`localStorage` はブラウザのデータ削除で消えます。同期を使わない場合は
「バックアップ」から JSON を書き出して保管してください。
